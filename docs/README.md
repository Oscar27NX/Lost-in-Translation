# Purpose: Index of Lost In Translation governance logs, research records, and plans.

- `PROJECT.md` — Project definition, problem statement, research questions, scope, and terminology.
- `METHOD.md` — Active translation pipeline, registered baseline/variants, and externalized config parameters.
- `DECISIONS.md` — Append-only record of design, method, and dataset decisions.
- `HYPOTHESES.md` — Testable hypotheses tied to research questions and runs.
- `IDEAS.md` — Unimplemented research and engineering proposals.
- `STATUS.md` — Current repository status, reviewed vs. unreviewed items, and exact next step.
- `MAP.md` — Inventory of directories and key source files.
- `plans/` — Approved implementation plans.
