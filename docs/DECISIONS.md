# Purpose: Append-only log of project, method, and dataset decisions.

## 2026-11-23

- **DEC-001 (D1 — Separate Variant Module for Operator Recall)**: Froze `backend/lit_core/latex_fmt.py` untouched as `symbolic_literal_v0_1` and placed the new balanced-argument operator translator in `backend/lit_core/latex_fmt_v2.py` (`symbolic_literal_v0_2`), selectable via `ModelConfig.symbolic_variant`. - **DEC-003 (D3 — Externalized Greek ASCII Allowlist)**: Externalized an explicit Greek variable allowlist (`alpha`..`psi`, intentionally excluding `omega`) into `backend/lit_core/configs/symbolic_operators.json`, converting exact Greek identifier tokens in math mode while leaving underscored identifiers such as `h_theta` untouched.
